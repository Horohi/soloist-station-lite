# 🎵 Spotify Soloist для Яндекс Станции Лайт 1

> **Spotify Connect клиент на базе официального движка Spotify Soloist (ARM64)**  
> Разработано специально для **Яндекс Станции Лайт 1** (`yandexmicro`, платформа Allwinner A133, ядро Linux `aarch64`).

Полноценный клиент **Spotify Connect** с **голосовым управлением через Алису**, **голосовым поиском любых треков/альбомов**, **аппаратными сенсорными кнопками**, **переключением цензуры мата** и **надёжным автозапуском при включении**.

---

## ✨ Возможности и фишки

- 🚀 **Официальный движок Spotify Soloist**:
  - Высочайшая стабильность — никаких разрывов воспроизведения, сбоев буферизации или рассинхронизации.
  - Качество звука до 320 kbps (Very High / Extreme).
  - 100% аппаратная синхронизация со шкалой громкости колонки (ALSA Master Playback Volume) и кнопками **+** / **-**.
- 🔍 **Голосовой поиск музыки через Алису**:
  - Поиск треков, исполнителей и альбомов на русском и английском языках.
  - Умный захват запроса: Алиса глушится за ~50 мс, запрос отправляется в Spotify Web API, и трек мгновенно стартует.
  - Автоматический обход геоблокировок Spotify (через SNI-прокси).
- 🤫 **Умное подавление фразы о подписке**:
  - При голосовых командах отправляются директивы Quasar IPC (`STOP_CONVERSATION`, `CANCEL_DIALOG_AND_CLEAR_QUEUE`, `STOP_TTS`), поэтому колонка не перебивает музыку сообщением *«Нужна подписка Яндекс Плюс»*.
- 🔞 **Голосовой переключатель цензуры (детский / взрослый режим)**:
  - *«Алиса, без мата»* / *«Алиса, включи цензуру»* — ищет только Clean-версии треков.
  - *«Алиса, с матом»* / *«Алиса, взрослый режим»* — разрешает треки с Explicit-контентом.
- 👆 **Сенсорная кнопка на корпусе колонки**:
  - Короткий тап по центру: **Play / Pause**.
  - Удержание центральной кнопки (> 0.6 сек): штатный вызов Алисы.
  - Кнопки **+** и **-**: регулировка громкости.
- 🔄 **Автозапуск и надёжность**:
  - Сервис автоматически стартует при включении питания колонки.
  - Встроенный watchdog: ожидает подключение к Wi-Fi и активирует устройство в Spotify Connect.

## 🗣️ Голосовые команды

### Воспроизведение и управление:
- *«Алиса, включи песню [название]»* (например: *«Алиса, включи песню Кукушка»*)
- *«Алиса, поставь [исполнитель] [трек]»* (например: *«Алиса, поставь Linkin Park Numb»*)
- *«Алиса, включи группу [название]»* (например: *«Алиса, включи группу Кино»*)
- *«Алиса, включи альбом [название]»* (например: *«Алиса, включи альбом Meteora»*)
- *«Алиса, включи музыку»* / *«Алиса, играй»* — возобновление воспроизведения
- *«Алиса, пауза»* / *«Алиса, стоп»* — пауза
- *«Алиса, дальше»* / *«следующий трек»* — следующий трек
- *«Алиса, назад»* / *«предыдущий трек»* — предыдущий трек
- *«Алиса, перемешай»* / *«вразброс»* — включить Shuffle
- *«Алиса, по порядку»* — выключить Shuffle
- *«Алиса, зацикли»* / *«повторяй»* — включить повтор трека
- *«Алиса, не повторяй»* — выключить повтор
- *«Алиса, громче»* / *«тише»* / *«громкость 4»* — регулировка громкости

### Цензура ненормативной лексики:
- *«Алиса, без мата»* / *«включи цензуру»* / *«детский режим»*
- *«Алиса, с матом»* / *«выключи цензуру»* / *«взрослый режим»*

## 📦 Быстрая установка

### 1. Подготовка
1. Подключитесь к колонке через ADB:
   ```bash
   adb connect <IP_КОЛОНКИ>:5555
   ```
2. (Опционально) Получите ключи поиска Spotify Web API:
   - Зайдите на [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard) и создайте приложение (любое имя).
   - Скопируйте `Client ID` и `Client Secret`.
   - Создайте файл `spotify_api.conf`:
     ```bash
     SPOTIFY_CLIENT_ID="ваш_client_id"
     SPOTIFY_CLIENT_SECRET="ваш_client_secret"
     ```

### 2. Установка на колонку
`install.sh` выполняется **на самой колонке** (нужны root и `aarch64`), а не на компьютере.
Скачайте релизный архив из раздела [Releases](../../releases) (в нём лежат `bin/soloist` и `lib64/`, которых нет в репозитории), затем:
```bash
tar -xzf soloist-station-lite.tar.gz
adb push soloist-station-lite /data/local/tmp/soloist-station-lite
adb shell "cd /data/local/tmp/soloist-station-lite && sh ./install.sh"
```
(Если нужно передать ключ и имя заранее: `sh ./install.sh <API_KEY> "<Имя устройства>"`.)

Скрипт автоматически:
- Скопирует все необходимые файлы на колонку в `/data/opt/soloist`
- Настроит права доступа и автозагрузку при старте колонки
- Запустит сервис Spotify Connect

### 3. Подключение приложения
Откройте приложение Spotify на смартфоне или компьютере, нажмите на значок устройств в плеере и выберите **«Yandex Station Lite»**.

## 🛠️ Сборка моста из исходников

Компиляция легковесного моста `soloist-bridge` (написан на чистом C без libc с прямыми системными вызовами Linux aarch64):

```bash
make
```

Или вручную через `clang`:
```bash
clang --target=aarch64-linux-gnu -fuse-ld=lld -static -fno-stack-protector -O2 -fno-builtin -nostdlib -o bin/soloist-bridge src/soloist-bridge.c
llvm-strip -s bin/soloist-bridge
```

├── uninstall.sh              # Скрипт полного удаления с колонки
├── spotify_api.conf.example  # Пример конфигурации Spotify API
├── Makefile                  # Сборка бинарников
