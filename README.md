# 🎵 Spotify Soloist для Яндекс Станций (Universal ARM64)

> **Полноценный Spotify Connect клиент на базе официального движка Spotify Soloist (ARM64)**  
> Поддерживает все умные колонки Яндекс с 64-битным ядром Linux (`aarch64`):
> - **Станция Лайт 1 & 2** (`yandexmicro`, `plum`)
> - **Станция Мини 2, 3, 3 Про** (`station-mini2`, `bergamot`, `pickle`)
> - **Станция 2** (`station-midi` в DT)
> - **Станция Миди** (`cucumber`)

Полноценный клиент **Spotify Connect** с **голосовым управлением через Алису**, **голосовым поиском любых треков/альбомов**, **аппаратными сенсорными кнопками** (с автоопределением сенсоров на любой модели), **переключением цензуры мата** и **надёжным автозапуском при включении**.

English guide: [Voice request lifecycle, configuration and tests](docs/VOICE_REQUESTS.md).

---

## ✨ Возможности и фишки

- 🚀 **Официальный движок Spotify Soloist**:
  - Высочайшая стабильность — никаких разрывов воспроизведения, сбоев буферизации или рассинхронизации.
  - Качество звука до 320 kbps (Very High / Extreme).
  - 100% аппаратная синхронизация со шкалой громкости колонки (ALSA Master Playback Volume) и кнопками **+** / **-**.
- 🔍 **Голосовой поиск музыки через Алису**:
  - Поиск треков, исполнителей и альбомов на русском и английском языках.
  - Запрос выполняется после финального результата распознавания; повторные состояния с тем же ID не запускают его заново.
  - Автоматический обход геоблокировок Spotify (через SNI-прокси).
- 🤫 **Умное подавление фразы о подписке**:
  - При голосовых командах отправляются существующие директивы Quasar IPC (`STOP_CONVERSATION`, `CANCEL_DIALOG_AND_CLEAR_QUEUE`, `STOP_TTS`, `CANCEL_DIALOG`). Подавление речи зависит от прошивки и требует проверки на колонке.
- 🔞 **Голосовой переключатель цензуры (детский / взрослый режим)**:
  - *«Алиса, без мата»* / *«Алиса, включи цензуру»* — ищет только Clean-версии треков.
  - *«Алиса, с матом»* / *«Алиса, взрослый режим»* — разрешает треки с Explicit-контентом.
- 💡 **Светомузыка и эквалайзер кольца LED (в стиле Nothing Phone)**:
  - Динамическая пульсация кольца подсветки в такт музыке (разделение на низкие/средние/высокие частоты).
  - По умолчанию стильный чистый белый цвет (Nothing Phone Glyph), настраивается в конфиге (любой цвет или Rainbow).
  - Автоопределение LED-зон на всех моделях Станций (3 зоны на Лайт 1/2, 6 зон на Мини 2, 24 зоны на Миди).
  - Безопасно для умного дома: команды управления светом в комнатах (*«выключи свет»*) не перехватываются!
- ⚡ **Удобный bash CLI (`soloist`)**:
  - Управление службой в одну команду: `soloist status`, `soloist update`, `soloist clean`, `soloist led on/off`.
- 🧠 **Глубокая оптимизация памяти и защита Flash**:
  - Потребление RAM плеера снижено со 100 МБ до ~44 МБ (glibc malloc tuning).
  - Включен zram-буфер в RAM (64 МБ сжатой памяти), предотвращающий OOM-киллер при звонках и нагрузке.
  - Мгновенная очистка кэша после каждого трека и защита NAND-памяти от износа (кэш перенаправлен в RAM).
- 👆 **Сенсорная кнопка на корпусе колонки**:
  - Короткий тап по центру: **Play / Pause**.
  - Удержание центральной кнопки (> 0.6 сек): штатный вызов Алисы.
  - Кнопки **+** и **-**: регулировка громкости.
- 🔄 **Автозапуск и надёжность**:
  - Сервис автоматически стартует при включении питания колонки.
  - Встроенный watchdog: ожидает подключение к Wi-Fi и активирует устройство в Spotify Connect.

## 🗣️ Голосовые команды

### Воспроизведение и управление:
- *«Алиса, включи песню [название]»* (например: *«Алиса, включи песню Кукушка»*)
- *«Алиса, поставь [исполнитель] [трек]»* (например: *«Алиса, поставь Linkin Park Numb»*)
- *«Алиса, включи группу [название]»* (например: *«Алиса, включи группу Кино»*)
- *«Алиса, включи альбом [название]»* (например: *«Алиса, включи альбом Meteora»*)
- *«Алиса, включи музыку»* / *«Алиса, играй»* — возобновление воспроизведения
- *«Алиса, пауза»* / *«Алиса, стоп»* — пауза
- *«Алиса, дальше»* / *«следующий трек»* — следующий трек
- *«Алиса, назад»* / *«предыдущий трек»* — предыдущий трек
- *«Алиса, перемешай»* / *«вразброс»* — включить Shuffle
- *«Алиса, по порядку»* — выключить Shuffle
- *«Алиса, зацикли»* / *«повторяй»* — включить повтор трека
- *«Алиса, не повторяй»* — выключить повтор
- *«Алиса, громче»* / *«тише»* / *«громкость 4»* — регулировка громкости

### Цензура ненормативной лексики:
- *«Алиса, без мата»* / *«включи цензуру»* / *«детский режим»*
- *«Алиса, с матом»* / *«выключи цензуру»* / *«взрослый режим»*

### Светомузыка и эквалайзер подсветки:
- *«Алиса, зажигай»* / *«Алиса, зажги»* — включить светомузыку Nothing Phone
- *«Алиса, покажи эквалайзер»* / *«Алиса, эквалайзер»* — включить аудио-эквалайзер
- *«Алиса, режим дискотека»* / *«Алиса, светомузыка»* / *«Алиса, дискотека»* — включить динамическую подсветку
- *«Алиса, стоп дискотека»* / *«Алиса, останови дискотеку»* — выключить подсветку
- *«Алиса, стоп эквалайзер»* / *«Алиса, погаси подсветку»* / *«Алиса, хватит светить»* — выключить подсветку
> 💡 Команды намеренно не содержат слов *«включи»* и *«выключи»*, поэтому команды умного дома (*«включи/выключи свет»*) и поиск треков работают без каких-либо конфликтов! Подсветка использует нелинейную квадратичную кривую чувствительности: при тихом звуке светодиоды не мерцают, а на битах и дропах ярко вспыхивают.

## 🛠️ Управление через CLI (`soloist`)

На колонке доступна удобная консольная утилита:
```bash
soloist status       # Статус демона, памяти, VmRSS, моста и текущего трека
soloist led on       # Включить светомузыку (белый цвет Nothing Phone)
soloist led off      # Выключить светомузыку
soloist led rainbow  # Режим вращающейся радуги (RGB)
soloist clean        # Быстрая очистка диска /data, логов и кэша
soloist update       # Обновление до свежей версии с GitHub в 1 команду
soloist restart      # Перезапуск службы
soloist logs bridge  # Просмотр логов моста в реальном времени
```

## 📦 Быстрая установка

### 1. Подготовка
1. Подключитесь к колонке через ADB:
   ```bash
   adb connect <IP_КОЛОНКИ>:5555
   ```
2. (Опционально) Получите ключи поиска Spotify Web API:
   - Зайдите на [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard) и создайте приложение (любое имя).
   - Скопируйте `Client ID` и `Client Secret`.
   - Создайте файл `spotify_api.conf`:
     ```bash
     SPOTIFY_CLIENT_ID="ваш_client_id"
     SPOTIFY_CLIENT_SECRET="ваш_client_secret"
     ```

### 2. Установка на колонку

#### Вариант А. Автономная установка через `install.sh`
`install.sh` выполняется **на самой колонке** (нужны root и `aarch64`), а не на компьютере.
Скачайте релизный архив из раздела [Releases](../../releases) (в нём лежат `bin/soloist` и `lib64/`, которых нет в репозитории), затем:
```bash
tar -xzf soloist-station-lite.tar.gz
adb push soloist-station-lite /data/local/tmp/soloist-station-lite
adb shell "cd /data/local/tmp/soloist-station-lite && sh ./install.sh"
```
(Если нужно передать ключ и имя заранее: `sh ./install.sh <API_KEY> "<Имя устройства>"`.)

#### Вариант Б. Установка через YAM v2 (Y Application Manager)
Проект содержит манифест `yam.yaml` и полностью адаптирован под спецификацию пакетов **YAM v2** (`.yampkg`):
```bash
# Сборка пакета для платформы (yandexmicro, yandexmini_2, yandexplum, yandexmidi):
yam --platform yandexmicro pack . --output soloist.yampkg

# Установка пакета:
yam install soloist.yampkg
```
YAM v2 автоматически зарегистрирует и запустит два системных сервиса: `soloist` (Spotify Connect клиент) и `bridge` (мост кнопок и Алисы).

Скрипт автоматически:
- Скопирует все необходимые файлы на колонку в `/data/opt/soloist`
- Настроит права доступа и автозагрузку при старте колонки
- Запустит сервис Spotify Connect

### 3. Подключение приложения
Откройте приложение Spotify на смартфоне или компьютере, нажмите на значок устройств в плеере и выберите **«Yandex Station Lite»**.

## 🛠️ Сборка моста из исходников

Компиляция легковесного моста `soloist-bridge` (написан на чистом C без libc с прямыми системными вызовами Linux aarch64):

```bash
make
```

Или вручную через `clang`:
```bash
clang --target=aarch64-linux-gnu -fuse-ld=lld -static -fno-stack-protector -O2 -fno-builtin -nostdlib -o bin/soloist-bridge src/soloist-bridge.c
llvm-strip -s bin/soloist-bridge
```
